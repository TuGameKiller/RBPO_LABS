# Library REST API

Бэкенд-сервис для автоматизации работы библиотеки: учет фонда, выдача книг и управление очередью ожидания.

**Стек:** Java (Spring Boot), JPA (Hibernate), PostgreSQL.

---

## Предметная модель

Сервис оперирует следующими сущностями:

*   `User`: Читатели библиотеки (имя, email, роль).
*   `BookEdition`: Данные об издании (автор, название, ISBN).
*   `Copy`: Физические экземпляры книг в фонде (инвентарный номер, статусы `AVAILABLE`/`BORROWED`).
*   `Loan`: Учет выданных книг (читатель, экземпляр, даты выдачи и возврата).
*   `WaitingRequest`: Заявки на получение занятых изданий (электронная очередь).

---

## Реализованная бизнес-логика

В приложении запрограммировано 5 ключевых сценариев:

1.  **Выдача экземпляра:** Регистрация займа, автоматический перевод физической копии в статус `BORROWED`.
2.  **Возврат и автопереуступка очереди:** При фиксации возврата книги система проверяет наличие ожидающих в очереди. Если очередь есть, книга автоматически оформляется на следующего читателя. В противном случае экземпляр становится доступным (`AVAILABLE`).
3.  **Продление займа:** Блокируется системой, если на данное издание зарегистрирована активная очередь от других читателей.
4.  **Регистрация очереди:** Постановка читателя в электронную очередь на получение издания в случае отсутствия свободных экземпляров.
5.  **Списание фонда:** Блокирует удаление физических экземпляров, которые в данный момент находятся на руках у читателей (статус `BORROWED`).

---

## Запуск и проверка

1.  Установите параметры подключения к PostgreSQL в `src/main/resources/application.yml`.
2.  Для проверки работоспособности используйте cURL-скрипты, расположенные в папке `src/main/java/org/example/scripts/`
